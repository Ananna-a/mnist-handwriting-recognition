# MNIST 手写数字分类识别 — 设计文档

**日期：** 2026-05-14  
**类型：** 多分类互斥（0-9 数字识别）

---

## 1. 项目目标

基于 MNIST 数据集，使用 TensorFlow/Keras 构建 CNN 卷积神经网络，实现对手写数字 0-9 的识别分类。提供 PySide6 手写画板 GUI 上位机，用户可鼠标手写数字并实时获得预测结果和置信度可视化。

## 2. 技术选型

| 类别 | 选型 | 原因 |
|------|------|------|
| 深度学习框架 | TensorFlow / Keras | 用户指定，Keras API 简洁 |
| GUI 框架 | PySide6 | 用户指定，Qt 官方 Python 绑定，LGPL |

## 4. 神经网络架构

CNN 模型（Keras Sequential）：

```
Conv2D(32, 3×3, ReLU) → MaxPool2D(2×2) →
Conv2D(64, 3×3, ReLU) → MaxPool2D(2×2) →
Flatten → Dense(128, ReLU) → Dropout(0.5) → Dense(10, Softmax)
```

- 优化器：Adam  
- 损失函数：Sparse Categorical Crossentropy  
- 评估指标：Accuracy  
- 训练参数：epochs=10, batch_size=64  
- 目标准确率：测试集 > 98%

## 6. GUI 界面（gui_app.py）

### 6.1 窗口布局

```
┌──────────────────────────────────────────┐
│  MNIST 手写数字识别                        │
├──────────────────────┬───────────────────┤
│   手写画板区域         │   预测结果：7       │
│   (280×280 黑色)      │   置信度：98.3%    │
│   鼠标按住拖动书写      │                   │
│                       │   ████████ 0      │
│                       │   ██ 1            │
│                       │   █ 2             │
│                       │   ██████████ 7    │
│                       │   █ 8             │
│                       │   ██ 9            │
├──────────────────────┴───────────────────┤
│  [ 清除画板 ]   [ 识别 ]   [ 模型: xxx.h5 ] │
└──────────────────────────────────────────┘
```

### 6.2 组件说明

| 组件 | 说明 |
|------|------|
| 手写画板 | 280×280 黑色画布，鼠标按住拖动绘制白色笔迹 |
| 预测结果显示 | 大字显示预测数字 + 置信度百分比 |
| 概率柱状图 | 横向柱状图展示 0-9 每个数字的预测概率 |
| 清除按钮 | 清空画布 |
| 识别按钮 | 缩放到 28×28 → 模型推理 → 更新结果 |
| 状态栏 | 显示当前加载的模型文件名 |

### 6.3 推理预处理管线

```
画布 280×280 → 缩放到 28×28 → 灰度归一化 [0,1] → reshape (1,28,28,1) → 模型预测 → softmax 概率
```
